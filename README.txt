Xiaohongshu corpus handoff bundle
Created: 2026-09-27

Contents: extracted note text and available comments, saved sanitized runtime snapshots, downloaded image files, image-to-note provenance, visual-review records, the source map, and the xhs-public-note skill.
The bundle contains no Chrome profile, cookies, model weights, or temporary browser profile. Xiaohongshu URLs are canonicalized and query strings are removed; sensitive URL parameters are redacted.

To restore: extract this ZIP at the root of the cloned repository. The archive preserves the .cache/xhs-extracted paths used by the indexes. The .cache directory is Git-ignored, so Git push alone will not transfer these files.
The GGUF model files are separate and are not part of this data bundle.
