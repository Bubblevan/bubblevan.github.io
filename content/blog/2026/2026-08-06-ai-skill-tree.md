## 一张图引发的焦虑

小红书博主「赛博大喇叭」发了一张图（2480 赞 / 1002 收藏），标题是：

> 我们现在要学的东西居然有这么多！只差了 4 年！居然要多学这么多东西！都怪 AI！

![AI 技能树 2022 vs 2026](/blog/2026/ai-skill-tree-2022-vs-2026.jpg)

这张图的核心价值在**结构对比**：左边是 2022 年的技术栈（一列字就写完了），右边是 2026 年的（一整面墙）。

## 2022 年：Prompt 就够了

左侧时间线（2022）的技术栈：

- ChatGPT
- Claude
- Prompt
- Function Calling
- 向量数据库
- 微调 / Fine-tuning
- 评估 / Evaluation
- 框架 / Frameworks

一句话：**会写提示词 + 会调 API + 会做 RAG**，就是当年的"AI 工程师"。

## 2026 年：一整面墙

右侧（2026）的工程化能力：

| 类别 | 具体技能 |
|------|---------|
| **Harness / 编排** | Harness Engineering、Loop Engineering、Graph Engineering、Multi-Agent Systems |
| **协议 / 连接** | MCP、Stateless MCP、AI Gateways、Tool Use |
| **上下文 / 记忆** | Context Engineering、Memory Layers、RAG 2.0 |
| **模型 / 数据** | Fine-tuning、Synthetic Data、Distillation |
| **质量 / 治理** | Evaluation、Guardrails、Observability、Prompt Optimization |
| **成本 / 运营** | Cost Optimization、And more... |

## 我的看法

这张图的"焦虑感"是真的，但要用对方式：

1. **不是全都要学**——评论区老洪说得对，左边是"会用工具"，右边是"能造工具"。日常用 AI 只需要左边，专业做 AI 工程才需要右边
2. **但右边确实是趋势**——我自己最近在学的 Harness 方法论、MCP、Agent 编排，全在这面墙上。2022 年的"Prompt 工程师"确实已经不够了
3. **挑方向深耕**——麦克雷的"赌对方向"论虽然糙，但方向选择 > 全都要学，是共识

这张图值得存：以后回顾 2026 年 AI 工程技能栈，它是个不错的参照系。
