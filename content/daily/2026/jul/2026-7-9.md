## 今日总结
### Stablepay
#### [OWS](https://learnblockchain.cn/article/24557#:~:text=Open%20Wallet%20Standard,%28OWS%29%20%E6%98%AF%E4%B8%80%E7%A7%8D%E5%AE%89%E5%85%A8%E3%80%81%E6%9C%AC%E5%9C%B0%E4%BC%98%E5%85%88%E7%9A%84%E5%8D%8F%E8%AE%AE%EF%BC%8C%E6%97%A8%E5%9C%A8%E4%B8%BAAI%E4%BB%A3%E7%90%86%E5%92%8C%E5%BC%80%E5%8F%91%E8%80%85%E5%B7%A5%E5%85%B7%E6%8F%90%E4%BE%9B%E7%BB%9F%E4%B8%80%E7%9A%84%E8%B7%A8%E9%93%BE%E5%AF%86%E9%92%A5%E5%AD%98%E5%82%A8%E3%80%81%E9%92%B1%E5%8C%85%E7%AE%A1%E7%90%86%E5%92%8C%E4%BA%A4%E6%98%93%E7%AD%BE%E5%90%8D%E8%A7%A3%E5%86%B3%E6%96%B9%E6%A1%88%E3%80%82%20%E5%AE%83%E8%A7%A3%E5%86%B3%E4%BA%86%E5%BD%93%E5%89%8DAI%E4%BB%A3%E7%90%86%E9%92%B1%E5%8C%85%E7%A2%8E%E7%89%87%E5%8C%96%E5%92%8C%E4%B8%8D%E5%AE%89%E5%85%A8%E7%9A%84%E5%AF%86%E9%92%A5%E7%AE%A1%E7%90%86%E9%97%AE%E9%A2%98%EF%BC%8C%E5%B9%B6%E6%94%AF%E6%8C%81%E6%9C%AC%E5%9C%B0%E9%83%A8%E7%BD%B2%EF%BC%8C%E9%81%BF%E5%85%8D%E4%BA%86%E5%AF%B9%E4%BA%91%E6%9C%8D%E5%8A%A1%E7%9A%84%E4%BE%9D%E8%B5%96%E5%92%8C%E9%AB%98%E5%BB%B6%E8%BF%9F%E3%80%82)无法运行在Windows上
在 Windows 原生环境下，`@open-wallet-standard/core` v1.4.2 官方从未提供过 Windows 平台的原生二进制包。`npm install` 成功是假象（因为原生包被声明为 optionalDependencies，缺失不中断安装），运行到签名逻辑时必定报“没有可用的签名驱动”。这不是安装步骤错误，而是上游平台限制。
- `win32` 不等于“32位系统”。这是 Node.js 生态的固定历史命名，所有 Windows 系统（无论 64 位还是 32 位）的 `process.platform` 返回值均为 `win32`。
- 真正区分位数的是后缀：`x64` 表示 64 位，`ia32` 表示 32 位。
- `msvc` 表示使用微软 VC++ 运行时编译，是 Windows 原生模块的标准编译目标。
- 因此 `@open-wallet-standard/core-win32-x64-msvc` 这个包名是“Windows 64 位专用包”的标准写法，命名完全合规，只是官方从未发布过。

**可查证的具体证据（为什么判断为平台限制）**：
1. 官方已发布的平台原生包清单（npm 维护者公开包列表）：
   - `@open-wallet-standard/core-darwin-arm64`（苹果硅 macOS）
   - `@open-wallet-standard/core-darwin-x64`（Intel 芯片 macOS）
   - `@open-wallet-standard/core-linux-arm64-gnu`（ARM 架构 Linux）
   - `@open-wallet-standard/core-linux-x64-gnu`（x86 架构 Linux）
   上述清单中没有任何 `win32` 或 `windows` 前缀的包，历史所有版本也从未发布过 Windows 包。

2. npm 公共仓库检索结果：
   - 包名 `@open-wallet-standard/core-win32-x64-msvc` 在 npm 上完全不存在。其他项目（如 oxc、swc）虽有类似后缀，但与 OWS 无关。
   - 这正是运行时加载失败的直接原因：代码按平台查找原生包，但找不到对应文件。

3. 官方安装脚本的设计：
   - 官方推荐的一键安装命令为 `curl -fsSL https://docs.openwallet.sh/install.sh | bash`，这是一个纯 bash 脚本，Windows 原生环境（CMD/PowerShell）无法直接执行。
   - 这从产品设计层面说明 Windows 并非官方首发支持平台。

4. 版本历史澄清：
   - 不是 `1.4.2` 去掉了 Windows 支持，而是从 `1.0` 首发到 `1.4.2` 的所有版本，官方都从未发布过 Windows 原生二进制包。
   - “安装成功”是因为 `optionalDependencies` 机制，缺失不会中断 npm 安装；但运行阶段加载签名驱动时必然失败。
