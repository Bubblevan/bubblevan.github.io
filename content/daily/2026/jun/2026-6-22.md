### stablepay
**优先级最高、落地最快、效果最好的是给 npx 包新增一个 `install` 交互式一键安装命令**——用户全程不用找配置文件、不用手写 JSON，终端跑一行命令、点选自己用的 AI 宿主，就能自动完成配置。

### 方案一：自带交互式一键安装 CLI
这是成本最低、覆盖宿主最全、用户体验提升最明显的方案。直接在你现有的 `stablepay-agentpay-dev` npm 包中新增一个 `install` 子命令，用户只需要执行一行命令：
```bash
npx stablepay-agentpay-dev install
```
后续全程交互式引导，自动完成所有配置，完全不用用户手动修改文件。

#### 核心实现逻辑
1. **自动检测用户已安装的宿主**
   程序自动扫描本地 Claude Desktop、Claude Code、Cursor、OpenClaw 等常见 MCP 宿主，列出可安装的选项，用户勾选即可。
2. **自动定位配置文件路径**
   内置全平台各宿主的标准配置路径，不用用户手动找文件。主流宿主默认路径如下：

   | 宿主 | Windows 路径 | macOS / Linux 路径 | 配置字段 |
   |------|-------------|--------------------|----------|
   | Claude Desktop | `%APPDATA%\Claude\claude_desktop_config.json` | `~/.config/Claude/claude_desktop_config.json` | `mcpServers` |
   | Claude Code | `%USERPROFILE%\.claude\config.json` | `~/.claude/config.json` | `mcpServers` |
   | Cursor | `%APPDATA%\Cursor\User\settings.json` | `~/.config/Cursor/User/settings.json` | `mcpServers` |
   | OpenClaw | `%USERPROFILE%\.openclaw\openclaw.json5` | `~/.openclaw/openclaw.json5` | `mcp.servers` |

3. **安全写入配置**
   - 修改前自动备份原配置文件（生成 `.bak` 后缀副本），出错可回滚
   - 用对应格式解析器（JSON / JSON5）读写，避免手动编辑导致的语法错误
   - 自动去重：已存在 `stablepay` 条目则更新配置，不重复添加
   - 严格保持原文件的其他配置不变，只注入 MCP 服务项

4. **收尾引导**
   安装完成后提示用户重启对应宿主，直接说「帮我初始化 StablePay」即可开始使用。

#### 额外扩展能力
- 支持指定宿主安装：`npx stablepay-agentpay-dev install --host claude-desktop`
- 支持批量安装所有已检测到的宿主
- 配套 `uninstall` 命令，一键从所有宿主中移除配置
- 你现有的 `doctor` 命令可以扩展：检测各宿主的配置是否正确，异常时自动修复

### 方案二：适配官方 MCP CLI
MCP 官方提供了标准化的 CLI 管理工具 `@modelcontextprotocol/cli`，是整个生态通用的 MCP 包管理器。适配之后，用户可以用统一的命令安装所有 MCP 服务，不用记每个工具的专属命令。

#### 用户侧使用方式
```bash
# 安装官方 MCP 管理器
npm install -g @modelcontextprotocol/cli

# 一键安装 StablePay
mcp install stablepay-agentpay-dev
```
安装后会自动注册到所有支持的 MCP 宿主，和你手动写配置的效果完全一致，但符合整个生态的使用习惯，用户学习成本更低。

#### 适配成本
只需要在你的 `package.json` 中补充标准的 MCP 清单字段，声明启动命令、工具描述等元数据，即可被官方 CLI 识别，适配工作量很小。
