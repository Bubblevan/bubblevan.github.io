#### CU Link 官方 PDF 已核对

官方文件：[Collection of CU Link (Student Card) for New Postgraduates 2026-27](https://culink.cuhk.edu.hk/wp-content/uploads/2026/07/Collection-of-CU-Link-Student-Card-for-New-Postgraduates-2026-27.pdf)

本地原件：`D:\MyLab\_data_archive\Collection-of-CU-Link-Student-Card-for-New-Postgraduates-2026-27.pdf`

已确认的信息：

- 完成 online registration、满足 admission conditions（如适用）、学术资格核验，并上传 landing slip 和非本地生 HKID 后，才可以在 CU Link Self-Service 查询学生卡是否 ready；也可以致电 CU Link Card Centre `3943 8507` 查询。
- 卡 ready 后，非本地研究生可选择香港地址挂号邮寄或本人领取；邮寄需要有效香港地址，因此当前没有香港地址时走本人领取是合理路径。
- 本人领取需要先在 Self-Service 确认 card readiness，再通过 Online Booking System 预约，并携带身份证明文件到 CU Link Card Centre。
- PDF没有写出一个统一的学生卡领取截止日期；它写的是“卡 ready 后查询并办理领取”。

由此对当前状态的判断：学校邮件只让参考 PDF，并没有单独确认“上传 acknowledgement 后是否自动转交”或“9 月 11 日办理是否影响学生身份”；但 PDF明确要求上传 HKID card，而不是只写 acknowledgement。上传材料后应等待系统更新，再查询 card readiness，而不是默认立即可领取。

#### HKID 办理之后：CUHK 健身房 TODO

如果这几天不急着进 CUHK 健身房，等**实体 HKID 拿到手**后再开始，不走 Temporary User、小白条和佐敦人工认证的临时路线。

- [ ] 登录 SmartPLAY → `Activity`，搜索“正確使用健身室設施簡介會 / Briefing on Proper Ways to Use Fitness Equipment”。筛选 3 小时、免费、15 岁以上且有余位的场次。
- [ ] 报名后保存成功截图；上课当天提前约 30 分钟到场，完成理论、器械实操和 written assessment。
- [ ] 通过后在 SmartPLAY 的 User Profile 确认出现 `Fitness Room User` 资格，并保存截图或 PDF。
- [ ] 申请 CUHK `University Fitness Room User Certificate`；选择 LCSD qualification，上传 SmartPLAY 资格证明。CUHK 申请处理时间按资料记为最多 7 个工作日。
- [ ] 收到 CUHK 批准后，带 CU Link 和 HK$25 到 University Sports Centre 办理。
- [ ] 缴费后等待最多约 3 个工作日，确认 CU Link 的健身房权限已开通。
