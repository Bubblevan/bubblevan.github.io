Dreaming: Better memory for a more helpful ChatGPT
https://openai.com/index/chatgpt-memory-dreaming/

1. 核心变化: OpenAI 这次把 ChatGPT memory 从显式保存的笔记，推进到会话外整理和更新的长期上下文系统。
2. 记忆演进: 2024 年 saved memories 依赖用户明确要求记住，2025 年引入 dreaming，2026 年发布更强、更省计算的 dreaming 架构。
3. 三个目标: 新系统围绕 freshness、continuity 和 relevance 评估记忆质量，分别处理过期信息、跨会话连续性和相关记忆选择。
4. 产品价值: 对普通用户来说，它减少重复交代背景，让旅行、长期项目、偏好约束和复杂购买建议更贴合当前状态。
5. 工程门槛: OpenAI 称近期改进让服务 dreaming 所需计算量降低约 5 倍，因此可以扩展到 Free 用户并提升 Plus 和 Pro 记忆容量。
6. 用户控制: memory summary page 让用户查看、补充、纠正和管理系统综合出的记忆，是自动记忆能否被信任的关键入口。
7. 风险边界: 自动记忆要处理隐私、错误记忆、过期信息和记忆污染，不能把一次性情境长期当成用户偏好。
