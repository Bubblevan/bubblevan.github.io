## 主题与内容类型

本批次以论文、研究博客和开源项目合集为主。主要反复出现：强化学习与后训练、推理和模型架构、Agent与自动化研究、编码Agent与评测、安全与可解释性、训练/推理系统、数学与AI for Science、多模态生成。另有研究生涯、就业建议和个人鼓励内容。以下是按题目和正文线索粗分，不是严格标注。

- 按笔记题目/正文粗分：blog 20篇；paper 16篇；mixed/other 9篇；project 3篇。
- 作者会分享冷门但扎实的工作，也偏好解释清楚、实验充分的 blog、benchmark 和项目记录；合集图序不代表总体排名。
- 一条作者回复说大约每10—20篇挑1篇深读，其余先交给 Agent 摘要；博客更倾向亲自读观点。这是作者自述。

## 发现入口与原始信源

1. **X 推荐流**：作者建议持续点赞合口味的泛学术内容，逐步扩展推荐。
2. **研究者时间线**：从有价值的论文找到作者，再沿 X timeline 递归找其他研究者。
3. **AlphaXiv 与论文榜单**：作为近期论文候选的补充入口。
4. **师友推荐**：同行、导师和朋友推荐用于补足榜单偏差。

候选发现入口与原始材料核验应分开：X推荐和AlphaXiv用于发现；arXiv/论文项目页确认版本与摘要；研究者、实验室、公司技术博客用于解释；GitHub核验代码、数据和复现；Hugging Face及项目主页确认模型、数据卡和demo。图中频次是可见线索计数，不代表质量或热度排名。
